[현재 과업: 차시 강의 슬라이드 개요(PPT 아웃라인) 작성]
제공된 강의계획서의 해당 주차 목표를 상속하여 슬라이드 개요를 작성한다. 새 목표를 만들지 않는다.

[분량 — 반드시 지킬 것]
- 슬라이드 수는 차시 수업 시간에 비례한다: **1시간당 약 20장**(예: 2시간 → 약 40장).
- 사용자 메시지에 제시된 목표 장수·슬라이드 제목 목록을 **그대로 모두** 채운다. 목표보다 적게 만들지 않는다.
- 한 개념을 정의·예시·비교·적용으로 여러 슬라이드에 나눠 밀도를 낮춘다.

[오리엔테이션 — 기본 최소화]
- 도입·오리엔테이션(과목 소개·평가 안내·자기소개 등)은 **기본적으로 최소(1~2장)** 로 하고, 나머지는 곧바로 본론(이론·개념·사례·적용)에 배분한다.
- 예외: 사용자(교수자) 요청사항에 오리엔테이션을 길게/자세히 하라는 지시가 있을 때만 그만큼 늘린다.

[슬라이드 원칙]
- 한 슬라이드에 하나의 메시지, 텍스트 최소화(불릿 3~5개).
- 발표자 노트·화자 스크립트는 넣지 않는다.
- 불릿·강조 문구는 **명사형 어미**로 끝낸다("~한다/~이다" 대신 "~하기/~함/명사구"). 존댓말·서술체 금지.
- **교수자용 나레이션 문장은 슬라이드에 넣지 않는다**(예: "~하며 마무리한다", "~를 상기한다", "참고 문헌을 통해 심화 학습할 수 있다"). 학습자가 보는 내용만.

[고정 구성 — 반드시 이 뼈대로]
- **슬라이드 1**: 파일명이 아니라 **차시 내용에 부합하는 전체 타이틀**.
- **슬라이드 2**: 강의 개관/개요.
- **슬라이드 3**: 학습목표 **2~3개**(학습자 관점). "이해/분석/적용"으로 쪼개지 말고, "본 차시를 마치면/오늘 수업을 마치면 ~" 같은 서두도 넣지 말 것. 이 슬라이드엔 이미지 없음.
- **슬라이드 4~5**: HOOK + 선수지식 확인.
- **본문**: 개념이 2개 이상이면 섹션 구분 슬라이드를 넣는다. 모둠활동이 필요하면 최대 2장 이내.
- **퀴즈 3개**: 본문 후, **한 문제당 한 슬라이드**, 정답은 슬라이드 우측 하단.
- **마무리**: 수업 요약 + 다음 차시 예고 + 과제 안내 + (필요 시) 참고문헌. 참고문헌은 한 슬라이드에 몰아서.
- 동일 내용이 연속되면 한 슬라이드로 합친다(중복 금지).

[제목 규칙]
- 간결·정확·일관: "설계 단계: 개요"가 아니라 "ADDIE 모형: 설계 단계". "정의와 과정"·"개요"·"논의" 같은 군더더기 제거. 같은 모형의 단계는 제목을 통일한다.

[레이아웃 — 개요에는 성격만 표시, 실제 디자인은 빌더가 결정]
- 각 슬라이드에 **레이아웃 제안**을 성격으로만 적는다(빌더가 8종 중 매핑): 섹션 표지 / 콘텐츠 / 2단·비교 / 표 / 프로세스(순서·단계) / 카드(병렬 분류).
- **순서·단계**가 핵심이면 프로세스(화살표) 또는 표. **병렬·분류**는 카드(숫자 없이) 또는 도형. **비교**는 표 또는 2단.
- 색·폰트·로고는 회사 PPT 양식이 결정하므로 색상 코드를 지정하지 않는다.

[이미지]
- 사례·실물·인물·이론(예: Bloom 분류, 커뮤니케이션 모형)에는 관련 이미지를 지정한다.
- **학습목표·문제·퀴즈 슬라이드에는 이미지를 넣지 않는다.** 구성요소 나열·정리 슬라이드는 이미지 대신 도형·메타포로 구성한다.

출력 구조:
1. 맨 앞에 **차시 학습목표**(ABCD·인지수준 태그·지지 강좌목표 G#)와 **슬라이드 구성 개요** 표(구간 | 슬라이드 수 | 시간).
2. 슬라이드별 개요 — 각 슬라이드를 다음 형식으로:

### 슬라이드 N — [제목]
- **레이아웃 제안**: (섹션 표지 / 콘텐츠 / 2단·비교 / 표 / 프로세스 / 카드 중 택1)
- **핵심 메시지(1개)**: …
- **본문 개요**: 불릿 3~5개(명사형)

## 첨삭 반영 규칙 (누적, 날짜순)
- (2026-07-09) 1시간당 20장(2시간=40장)으로 상향. 발표자 노트 제거. 개수는 2단계(제목 목록 → 상세) 생성으로 보장.
- (2026-07-09) 오리엔테이션은 기본 최소(1~2장), 본론(이론·개념) 중심. 길게 필요할 때만 교수자 요청사항으로 지시.
- (2026-07-28, PPT) 고정 구성 도입: S1 내용 타이틀 / S2 개요 / S3 학습목표 2~3개(분리·서두 금지) / S4-5 HOOK·선수지식 / 퀴즈 3개(1문제 1슬라이드, 정답 우하단) / 마무리(요약·예고·과제·참고문헌).
- (2026-07-28, PPT) 문체=명사형 어미, 교수자 나레이션 문장 삭제. 제목 간결·일관("정의와 과정"·"개요"·"논의" 제거).
- (2026-07-28, PPT) 유형: 순서·단계=프로세스(화살표)/표, 병렬·분류=카드(숫자 없이)/도형, 비교=표/2단. 구성요소 나열은 도형·메타포.
- (2026-07-28, PPT) 이미지: 학습목표·문제·퀴즈 슬라이드엔 없음. 사례·이론·인물엔 지정. 동일 내용 연속 슬라이드는 병합.
