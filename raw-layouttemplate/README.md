# 슬라이드 레이아웃 견본 (디자인 제출 기준)

슬라이드 디자인을 새로 받을 때 **이 파일 형식으로 제출받는다.**
여기 들어온 PPTX 를 읽어서 색·글꼴을 뽑아 `templates/*.json` 으로 만들고,
프로그램이 그 배색으로 슬라이드를 자동 생성한다.

## 파일

| 파일 | 내용 |
|---|---|
| `260805-레이아웃견본13종_템플릿리디자인.pptx` | 13장 · 16:9 (13.33 × 7.5 in) |

13장은 **색이 아니라 형태가 13가지**다. 표지 · 섹션 · 목차 · 복습 · 학습목표 ·
문제제기 · 용어 · 연결 · 도해 · 수치 · 확인 · 예고 등 강의에서 반복되는 화면 종류다.

## 디자인하는 분께

1. **13장의 형태를 유지한다.** 장을 지우거나 순서를 바꾸면 어느 레이아웃인지 알 수 없다.
   색·글꼴·여백·선 굵기·도형 모양은 자유롭게 바꾼다.
2. **글자는 실제로 넣는다.** 빈 상자만 있으면 글자 크기와 줄간격을 읽을 수 없다.
3. **사진 자리는 자리표시 도형으로 남긴다.** 프로그램이 그 위치·크기에 사진을 넣는다.
   비율은 **1:1 에 가깝게**(0.9 ~ 1.0) 잡아 주기 바란다 — 가운데를 잘라 채우므로
   가로로 긴 상자를 쓰면 인물의 머리나 발이 잘린다.
4. **글꼴은 시스템에 있는 것**을 쓴다. 없는 글꼴을 지정하면 받는 쪽에서 다른 글꼴로 대체된다.
5. 배경색 위에 글자를 올릴 때 **명도 대비 4.5:1** 을 넘긴다. 넘지 못하면 프로그램이
   자동으로 글자색을 바꾸거나 어두운 배경으로 교체하므로 의도와 달라진다.

## 프로그램에 반영하는 법

이 PPTX 에서 색을 뽑아 `templates/` 에 JSON 한 개를 만들면 끝이다.
기존 배색은 지우지 않고 **템플릿으로 함께 보관**한다 — 이미 만든 강의를
다시 렌더할 때 색이 바뀌면 안 된다.

```
templates/navy-amber.json        기존 (남색 + 호박색)
templates/260805-redesign.json   이 견본에서 뽑은 것 (하늘색 + 초록)
```
